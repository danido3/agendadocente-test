# Agenda IPIA — versione di prova

Agenda scolastica per organizzare lezioni settimanali, impegni e sospensioni didattiche.

Questo repository, `agendadocente-test`, è dedicato alle prove.

## Primi passi

1. Apri l’app e vai in **Impostazioni → Personalizzazione**.
2. Aggiungi almeno una materia e una classe, usando il pulsante **＋** per ciascuna voce.
3. Premi **＋ Aggiungi** e scegli **Lezione settimanale** oppure **Impegno scolastico**.
4. Compila i campi e premi **Salva**.
5. Consulta le voci nelle schermate **Oggi**, **Settimana**, **Mese** e **Impegni**.

## Salvataggio e backup

L’agenda salva i dati nel browser del dispositivo. L’accesso Google e le funzioni cloud consentono il trasferimento dei dati e la sincronizzazione automatica facoltativa.

Per esportare una copia, apri **Impostazioni → Gestione avanzata → Backup e ripristino** e premi **Esporta backup completo**.

Conserva il file ottenuto prima di cancellare i dati del sito o ripristinare un altro backup.
